# Serpentine Academy of Code-Craft

This is a gamified, browser-based Python learning game in a wizarding-school setting. It takes you from your first `print()` to proficient Python across seven school "Years".

The mentor **never gives you the answer**. It asks guiding questions, sketches conceptual pseudocode, and points out architectural flaws until you fix the code yourself.
