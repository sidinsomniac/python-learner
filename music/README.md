# Background music

Drop audio files here (`.mp3`, `.m4a`, `.ogg`, `.opus`, `.wav`, `.aac` or `.flac`) and rebuild or restart `npm run dev`. The game plays them quietly in the background, shuffled and looping, with no visible player.

- Each track's title comes from its file name: `02-great-hall.mp3` shows as "Great Hall".
- Players turn music on or off with the 🎵 button in the header, and set the volume in Settings.
- **Everything in this folder except this README is ignored by git.** Personal copies of music stay on your machine and are never published. Use only audio you have the right to play.
- When we make our own tracks for the game, we'll un-ignore them in `.gitignore` so they ship with the build.
