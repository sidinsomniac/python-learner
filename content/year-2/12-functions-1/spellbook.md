# Functions

- `def name(param1, param2):` then an indented body. Call it: `name(a, b)`.
- `return value` gives the answer back and ends the function. No return -> `None`.
- **print shows; return gives.** Functions should return; callers print.
- Arguments match parameters by position.
- Returning early: once a `return` runs, the rest of the function is skipped.
- Functions can call other functions.
