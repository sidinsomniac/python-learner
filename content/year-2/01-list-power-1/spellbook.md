# List methods

- `append(x)`, `insert(i, x)`, `extend(other)` - add things.
- `pop()` / `pop(i)` - remove **and return** an item.
- `remove(x)` - remove the first `x` (ValueError if missing).
- `index(x)`, `count(x)` - find and count.
- `items.sort()` sorts in place and returns **None**; `sorted(items)` returns a new list.
- `reverse=True` for descending order.
- List methods change the list itself (strings never change).
