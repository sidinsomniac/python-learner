# break, continue, for-else

- `break` - leave the loop right now.
- `continue` - skip the rest of this pass; go to the next one.
- `for ... else` - the else runs only if the loop ended **without** `break`.
  Great for "search, and report if never found".
- Primes: above 1, dividing evenly only by 1 and themselves. 0 and 1 aren't prime; 2 is.
