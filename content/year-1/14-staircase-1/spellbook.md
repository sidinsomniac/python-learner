# if / elif / else

```python
if condition:
    ...          # runs when condition is True
elif other_condition:
    ...          # checked only if everything above was False
else:
    ...          # runs if nothing above was True
```

- A colon ends each `if`/`elif`/`else` line.
- Indented lines (4 spaces) belong to the branch above them.
- Branches are checked **top to bottom**; only the **first** True one runs.
