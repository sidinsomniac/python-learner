# for loops and range

```python
for item in collection:
    ...   # runs once per item
```

- `for ch in "text"` - one pass per character.
- `range(5)` gives 0, 1, 2, 3, 4. `range(2, 5)` gives 2, 3, 4.
- `range(10, 0, -2)` counts down: 10, 8, 6, 4, 2.
- The stop number is never included.
- Four nearly identical lines in a row? Use a loop.
