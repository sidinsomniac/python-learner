# Numbers, types and arithmetic

- `int` is a whole number, `float` has a decimal point, and `str` is text.
- `/` always gives a float: `6 / 2` is `3.0`.
- `//` is floor division: `7 // 2` is `3`.
- `%` is the remainder: `7 % 2` is `1` (handy for checking odd/even).
- `"7" + "3"` is `"73"` (string joining), but `7 + 3` is `10`.
- Use `type(x)` to find out a value's type.
