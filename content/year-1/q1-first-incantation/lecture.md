# Lesson 1: Speaking Parseltongue

Welcome, first-year! A **program** is just a list of instructions that the
computer follows **from top to bottom**, one line at a time. Here, we call
programs *spells*.

## Your first spell: `print`

`print` makes Python show something on the screen:

```python
print("Lumos")
```

Look closely at the three parts:

1. `print` - the name of the spell.
2. `( )` - round brackets. Whatever is inside is what the spell acts on.
3. `"Lumos"` - some text in quotes. Text in quotes is called a **string**.

## Strings

A string is any text wrapped in quotes. Double quotes `"..."` or single quotes
`'...'` both work - just use the same kind at both ends.

```python
print("Hagrid's hut")
print('Diagon Alley')
```

Without quotes, Python thinks you are naming something it should already
know. `print(Lumos)` is an error, because Python has never heard of a thing
called `Lumos`.

## Many lines

Each `print` shows one line. Two prints show two lines:

```python
print("Line one")
print("Line two")
```
