# Curriculum Map: the Seven Years

Each Year is one tier. You must pass a Year's **Trial** (boss project) to advance to the next Year.

| Year | Concepts | Trial (boss) |
|---|---|---|
| 1 | print/input, variables, types, arithmetic, strings, f-strings | Wizard ID-card generator |
| 2 | booleans, if/elif/else, while/for, range, break/continue | Number-guessing "Sorting Hat" game |
| 3 | lists, tuples, dicts, sets, slicing, comprehensions | Potion inventory manager |
| 4 | functions, args/kwargs, scope, recursion, exceptions | Spell-duel simulator |
| 5 | OOP: classes, inheritance, dunder methods, modules, packages | Magical creature registry (class hierarchy) |
| 6 | iterators/generators, decorators, context managers, file I/O, pytest-style testing | Spell library with persistence and tests |
| 7 | algorithms and Big-O, typing, dataclasses, stdlib (collections, itertools), async basics | Capstone: design your own mini-app |

## Rules that apply to every Year
- **Readability and PEP 8** are graded lightly from Year 3 onward.
- **Architectural-flaw feedback grows with each Year**:
  1. Years 1–2: naming
  2. Year 3: duplication
  3. Year 4: function design
  4. Year 5: class design
  5. Years 6–7: complexity
- **Spaced review**: every concept gets Duel trivia cards, which come back on an SRS schedule.
